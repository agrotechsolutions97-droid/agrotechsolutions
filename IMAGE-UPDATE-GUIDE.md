# Updating images and text

Images are in the `media` folder. Replace an existing image using the same filename and extension to keep the current page links working. Keep images compressed before upload and retain the original subject-appropriate filename.

After changing images or page text, upload the whole updated project folder as a new Cloudflare Pages deployment. Test the relevant page on mobile and desktop before publishing it to production.

Do not upload identity documents, customer photos, invoices, or any image that contains personal information without permission.
